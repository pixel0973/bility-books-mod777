# Ability Books (Fabric 1.20.1)

Книги с уникальными способностями. Сейчас есть книга «Костяной король» (3 способности).

## Сборка
Нужны: JDK 17 и интернет (Gradle сам скачает Minecraft и Fabric).

Вариант 1 (проще всего): открыть папку проекта в IntelliJ IDEA -> дождаться импорта Gradle -> справа вкладка Gradle -> Tasks -> build -> build.
Вариант 2: установить Gradle 8.5 и в папке проекта выполнить:
    gradle build
Готовый мод: build/libs/abilitybooks-1.0.0.jar (НЕ файл с -sources).

## Установка
1. Fabric Loader для 1.20.1 + Fabric API (0.92.2+1.20.1 или новее для 1.20.1).
2. Положить abilitybooks-1.0.0.jar в папку mods (и на клиент, и на сервер).

## Управление
- ЛКМ с книгой в руке — использовать выбранную способность
- Shift + ПКМ — переключить способность
- R — меню книги: дерево способностей на фоне пустоты. ЛКМ по открытому узлу — выбрать, по закрытому — прокачать за уровни опыта. Фон можно двигать мышью.
- Прокачка: 2-я способность — 40 уровней, 3-я — 50 уровней (уровни тратятся; порядок обязателен: сначала 1-я, потом 2-я, потом 3-я). Цены задаются в ability/Abilities.java (третий параметр Ability).

## Команды (оператор)
- /abilitybooks give <игроки> — выдать книгу (также есть во вкладке творческого меню «Книги способностей»)
- /abilitybooks unlockall <игроки> — открыть все способности
- /abilitybooks reset <игроки> — сбросить прогресс и перезарядки

## Как добавить новую книгу
1. В ability/Abilities.java добавить новый список способностей.
2. В ability/ можно добавить новый класс с действиями (как BoneKingActions).
3. В item/ModItems.java зарегистрировать новый AbilityBookItem, добавить текстуру
   assets/abilitybooks/textures/item/<имя>.png, модель models/item/<имя>.json и название в lang/*.json.

## Визуал способностей
- Костяное копьё: большое копьё (item_display с моделью `bone_spear_model`) появляется перед взглядом, висит ~0.5 с и вылетает вперёд. Если летит остриём назад — в `display/Displays.java` поставь `FLIP = true`.
- Костяные шипы: ~25 острий (`bone_spike_model`) вылезают из земли в зоне 4x5 и уходят обратно через 5 секунд.
